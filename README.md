# 연구실 탐색 지도

학부생용 연구실 탐색 해커톤 MVP. React + TypeScript + Vite로 구현했고, API 키나 로그인 없이 동작합니다.

체험은 보안 연구의 일곱 분야를 학부연구생 첫 주처럼 둘러봅니다. 들어가려면 SecAI Lab(구형준)을 고릅니다.

- 연구실: https://secai.skku.edu

- 분야: AI 보안, 프로그램 분석, 이상 탐지, 시스템 보안, 소프트웨어 테스팅, 사용자 인증, 네트워크 보안

## 실행

Node.js 22.18 이상 권장.

```powershell
npm.cmd install
npm.cmd run dev
```

```powershell
npm.cmd test
npm.cmd run build
```

## 학부연구생 체험

학생은 연구실이 다루는 분야를 하나씩 엽니다.

1. AI 보안, 프로그램 분석, 이상 탐지, 시스템 보안, 소프트웨어 테스팅, 사용자 인증, 네트워크 보안을 순서대로 봅니다.
2. 각 분야에서 연구실이 보는 것, 처음 해 보는 일, 질문을 읽습니다.
3. 더 알고 싶은 분야를 고르고, 이유와 랩미팅 질문을 남깁니다.

## 시연 확인 순서

1. ‘보안’ 입력 → SecAI Lab 선택 → 선택 이유 작성
2. 연구 비교 → 관심 과목 저장 → 비교 확인 → 체험
3. 분야를 하나씩 열기 → 관심 분야 고르기 → 둘러보기 저장
4. 준비 기록 작성 → 다음 행동 선택 → 저장 → Markdown 다운로드
