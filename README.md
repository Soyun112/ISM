# 연구실 탐색 지도

성균관대학교 소프트웨어학과의 연구실을 관심 분야에서 출발해 탐색하는 학부생용 MVP입니다. React + TypeScript + Vite로 구현했으며 로그인이나 API 키 없이 로컬에서 실행됩니다.

## 실행과 검증

Node.js 22.18 이상을 권장합니다. Windows PowerShell에서는 `npm.cmd`를 사용합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

개발 서버가 표시한 로컬 주소를 브라우저에서 엽니다. 자동 검증은 다음과 같습니다.

```powershell
npm.cmd test
npm.cmd run build
```

## 실제 데이터의 범위

- `SKKU_CS_연구실_연구분야.csv`의 59개 항목을 모두 앱 탐색 목록에 반영했습니다. 이 중 53개가 `연구실`이고, 나머지는 CSV에서 구분한 교수 연구분야·연구소입니다. CSV 원본은 수정하지 않았습니다.
- 기본 정보(소속, 탐색용 분야 분류, 교수, 연구실명, 주요 연구 분야, 홈페이지, 출처, 학부연구생 모집 여부, 비고)는 CSV의 값을 따릅니다. 빈 분류와 모집 여부는 화면에서 각각 `미분류`, `미확인`으로 표시합니다.
- 탐색용 분야 분류가 `보안·소프트웨어공학`인 8개 연구실만 공식 연구실·대학 페이지를 추가 조사하여 연구 개요, 연구 질문, 방법, 공개 논문, 학습 주제를 제공합니다. 나머지 항목에는 확인되지 않은 상세 내용을 만들어 넣지 않습니다.
- 논문은 해당 연구실의 전체 목록이 아닌 탐색을 돕는 사례입니다. 논문 제목·연도·게재처와 원문 목록 링크를 함께 제공합니다. 최형기 교수 연구실은 공개 교수 논문 목록에서 최근 항목을 확인하기 어려워 2018년 발표를 `기존 연구 사례`로 명시했습니다. 이은석 교수 항목은 CSV에 연구실 홈페이지가 없으므로 성균관대학교 공식 연구자 페이지를 사용했습니다.
- 학습 주제는 연구를 이해하기 위한 안내일 뿐 공식 개설 과목·담당 수업·선수과목이 아닙니다. 확인되지 않은 수업과 모집 정보는 추정하지 않습니다. 자료 확인일은 앱에 표시됩니다.

## 탐색 흐름

1. 관심 분야를 입력하거나 키워드를 선택하면 CSV의 분류·연구 분야와 일치하는 항목을 보여줍니다. 여러 후보를 선택하고 이유를 적을 수 있습니다.
2. `연구와 수업 알아보기`에서 선택한 후보의 기본 정보와 공식 출처를 비교합니다. 위 8개 연구실에는 연구 질문, 접근 방법, 논문 사례와 학습 주제를 더 자세히 설명합니다. 교수 담당 수업은 자료 확인 전까지 `미확인`으로 표시합니다.
3. 기존 BFS/A* 길찾기 체험은 실제 연구실과 직접 연결되지 않아 화면에서 제외했습니다. 연구실별 체험은 후속 작업으로 남겼습니다.
4. 관심 연구실, 이해하기 어려운 개념, 질문과 다음 행동을 기록하고 Markdown 요약을 다운로드할 수 있습니다. 탐색 기록과 도우미 대화는 현재 브라우저의 localStorage에 저장되며 다른 기기와 동기화되지 않습니다.

탐색 도우미는 CSV와 앱에 저장된 상세 정보만 안내하는 규칙 기반 기능입니다. 외부 AI 검색을 수행하지 않습니다. 최신 내용은 연구실 또는 대학 공식 페이지에서 다시 확인해야 합니다.

## 데이터 갱신 위치

| 위치 | 역할 |
| --- | --- |
| `SKKU_CS_연구실_연구분야.csv` | 원본 데이터 |
| `src/catalog.ts` | CSV 59행의 앱용 정적 스냅샷 |
| `src/data.ts` | CSV 항목 변환 및 8개 연구실의 검증한 상세 정보 |
| `src/recommend.ts` | 관심 표현과 CSV 분류·연구 분야의 일치 판단 |
| `src/content.ts` | 탐색 단계와 문구 |
| `src/chat.ts` | 저장된 정보 기반 도우미 응답 |
| `src/store.ts` | 브라우저 저장 형식과 손상 데이터 복구 |

CSV를 수정한 뒤에는 `src/catalog.ts`도 같은 행·열 순서로 갱신해야 합니다. 교수나 연구실 명칭이 바뀌면 선택 기록의 ID도 달라질 수 있으므로, 기존 브라우저 기록의 호환성을 확인하세요. 논문이나 모집 정보를 갱신할 때는 공식 출처와 확인일을 함께 검토하세요.

## 현재 제한

개별 연구실의 실시간 공지, 실제 담당 수업·개설 학기, 현재 학부연구생 모집 여부, 연구실별 체험, 외부 AI 연동은 제공하지 않습니다. `src/algorithms.ts`의 BFS/A* 구현과 과거 실험 저장 형식은 호환성을 위해 남아 있지만 현재 탐색 화면에는 노출하지 않습니다. 브라우저 저장 데이터를 삭제하면 탐색 기록을 복구할 수 없으므로 필요하면 Markdown 요약을 다운로드하세요.
